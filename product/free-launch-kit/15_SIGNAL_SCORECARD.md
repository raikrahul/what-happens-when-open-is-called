# Signal Scorecard (No Analytics Stack)

## Inputs (Manual)
Record daily:
1. number of X posts
2. number of technical replies
3. number of profile clicks (manual visible metric)
4. number of DMs asking for help
5. number of paid pack inquiries
6. number of paid purchases

## Weekly Score
- Content output score = posts published / planned posts
- Engagement score = technical replies / posts
- Buyer intent score = (DMs + inquiries) / posts
- Revenue score = purchases per week

## Decision Gates
1. If engagement score low for 2 weeks:
- increase failure-first hooks
- shorten posts

2. If engagement high, purchases low:
- improve CTA clarity
- show paid artifact preview

3. If purchases exist:
- keep cadence stable
- release next pro pack in 7 days
