# Content and Release Plan

## Weekly Output Target
1. One free artifact (worksheet or mini driver).
2. One paid artifact (advanced worksheet or forensic runbook).
3. One post (GitHub + one social platform).

## Free Pack Template
1. Problem statement.
2. Environment assumptions.
3. Driver code.
4. Trigger code.
5. Worksheet.
6. Expected output sample.
7. Failure checklist.

## Pro Pack Template
1. Extended cases.
2. Hard-mode debugging steps.
3. Pointer safety checks.
4. Validation matrix (multiple runs).
5. Interview-style challenge worksheet.

## Release Cadence
- Monday: scope + issue creation
- Tuesday: implementation
- Wednesday: worksheet writing
- Thursday: run verification and cleanup
- Friday: release + post
- Saturday: collect questions
- Sunday: prep next pack

## Naming Convention
- Free: `pack-free-YYYYMMDD-vX`
- Pro: `pack-pro-YYYYMMDD-vX`
