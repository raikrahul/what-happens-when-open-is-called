# Post Factory (Failure-First)

## Thread Blueprint (copy-paste)
1. Wrong: `<strong wrong claim>`
2. Data: `<one pointer/hash/error number>`
3. Breakpoint: `<where claim fails in call chain>`
4. Proof line 1: `<dmesg line>`
5. Proof line 2: `<dmesg line>`
6. Proof line 3: `<dmesg line>`
7. Action: `Fill worksheet:` <free link>
8. CTA: `Pro pack:` <paid link>

## Myth-breaker short post
- `Wrong: <claim>.`
- `Trace: <number>.`
- `Result: <correction>.`
- `Worksheet:` <link>

## Objection response format
- `Objection:` <quoted reply>
- `Check 1:` <numeric/log>
- `Check 2:` <numeric/log>
- `Check 3:` <numeric/log>
- `Conclusion:` <single line>

## No-go writing rules
1. no generic motivation text
2. no unverified broad kernel statements
3. no claim without one trace line
4. no CTA without artifact link
