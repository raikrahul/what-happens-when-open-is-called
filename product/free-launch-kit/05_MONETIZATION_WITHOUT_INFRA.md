# Monetization Without Infrastructure

## Allowed Free Stack
1. GitHub (code + docs)
2. GitHub Sponsors or Patreon or BuyMeACoffee or Gumroad
3. Email + GitHub Discussions

## Monetization Paths
1. Private repo access (monthly)
2. One-time paid pack ZIP/repo link
3. 1:1 sessions (fixed slots)
4. Team workshop (fixed agenda)

## Suggested Offer Table
1. Free
- public repo docs
- 1-2 public case packs

2. Pro Monthly
- private repo access
- weekly pro worksheet
- Q&A access

3. Pro One-Time Pack
- one advanced pack
- no subscription

4. Coaching Slot
- 60-min review
- pre-submitted logs

## Delivery Rules
1. Keep free and paid folders separated.
2. Keep changelog for every pack.
3. Give explicit prerequisites per pack.
4. Never sell without a runnable demo.

## Trust Rules
1. show exact commands
2. show exact logs
3. show known failures
4. show kernel version used
