# Product Shape

## Product Units
1. Free Unit: public case worksheet + public minimal trace driver.
2. Paid Unit: advanced case pack + pointer-forensics labs + review checklist.
3. Service Unit: 1:1 review call and troubleshooting session.

## Offer Ladder
1. Free
- 1-2 complete public cases
- public docs
- public trace examples

2. Paid Basic
- private repo access
- additional worksheets
- structured proofs and runbooks

3. Paid Pro
- everything in basic
- live session(s)
- priority Q&A

## Buyer Outcomes
1. Reproduce a claim from logs, not memory.
2. Build proof chain: probe entry -> probe return -> worksheet check.
3. Avoid false conclusions in dcache/dentry flows.

## Packaging Rule
Each case pack must include:
1. Driver source
2. Userspace trigger
3. Worksheet
4. Runbook
5. Expected dmesg pattern
6. Failure pattern list

## Non-goals
1. No dynamic web app.
2. No custom billing backend.
3. No infrastructure ops.
