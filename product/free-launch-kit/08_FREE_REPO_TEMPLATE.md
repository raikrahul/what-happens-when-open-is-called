# Free Repo Template

## Public Structure
- `README.md`
- `free-packs/`
- `docs/`
- `examples/`

## Public README must include
1. Why this exists
2. One 5-minute run path
3. One advanced run path
4. Link to paid offer
5. Link to discussion board

## Public Pack Constraints
1. Must run end-to-end
2. Must include worksheet
3. Must include expected dmesg snippet
